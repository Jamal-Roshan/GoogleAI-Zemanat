# راهنمای کامل نصب، راه‌اندازی و میزبانی سامانه در ویژوال استودیو و سرور محلی
## سامانه صدور و استعلام گواهی کسر از حقوق و ضمانت‌نامه بانکی (مدیریت آموزش و پرورش ملایر)
### مبتنی بر فناوری Blazor Interactive Server و دات‌نت ۱۰ (.NET 10)

---

## ۱. مشخصات فنی پکیج
- **فناوری هسته:** ASP.NET Core Blazor (دات‌نت ۱۰ / .NET 10)
- **محیط توسعه:** Microsoft Visual Studio 2026 یا Visual Studio 2022 (نسخه 17.12 به بالا)
- **پایگاه داده پیش‌فرض:** SQLite سازمانی محلی (بدون نیاز به نصب موتور دیتابیس جداگانه) + پشتیبانی کامل از Microsoft SQL Server
- **معماری:** Clean Architecture، تزریق وابستگی (DI)، Entity Framework Core
- **استاندارد بارکد:** ISO/IEC 15417 (Code 128) با چک‌سام Modulo-103 و QR کد استاندارد ISO/IEC 18004
- **امنیت کد رهگیری:** آنتروپی رمزنگاری ۶۰ بیت (CSPRNG) با قفل خودکار در برابر آزمون و خطای مکرر
- **کاربر مدیر اولیه:** نام کاربری `admin` و کلمه عبور `admin` (دارای تمام نقش‌های مدیر، اپراتور، تاییدکننده و پرسنل)

---

## ۲. پیش‌نیازهای نرم‌افزاری
1. **دات نت اس‌دی‌کی (.NET 10 SDK):**
   - دانلود از سایت رسمی مایکروسافت: https://dotnet.microsoft.com/download/dotnet/10.0
   *(در صورت استفاده از .NET 9 کافی است در فایل `EducationCertPortal.csproj` تگ `<TargetFramework>` را به `net9.0` تغییر دهید).*
2. **محیط توسعه ویژوال استودیو:**
   - Visual Studio 2022 یا Visual Studio 2026 با فعال بودن تیک **ASP.NET and web development**.
3. **جهت میزبانی روی IIS (در سرور محلی):**
   - نصب **.NET Core Hosting Bundle** مربوط به دات‌نت.

---

## ۳. نحوه باز کردن و اجرای پروژه در ویژوال استودیو
1. فایل زیپ پکیج را در مسیر دلخواه سیستم خود استخراج (Extract) نمایید.
2. روی فایل **`EducationCertPortal.sln`** دوبار کلیک کنید تا در Visual Studio باز شود.
3. در پنجره **Solution Explorer**، روی پروژه `EducationCertPortal` کلیک راست کرده و گزینه **Set as Startup Project** را انتخاب کنید.
4. کلید **F5** یا دکمه سبزرنگ **Run (https / http)** را در نوار بالای ویژوال استودیو بفشارید.
5. سیستم به طور خودکار:
   - پکیج‌های Nuget را بارگذاری می‌کند.
   - پایگاه داده SQLite با نام `EducationCertPortal.db` را ایجاد و جداول را می‌سازد.
   - کاربر مدیر اولیه (`admin`) و اطلاعات سازمانی ملایر را Seed می‌کند.
   - مرورگر شما روی آدرس `http://localhost:5000` یا `https://localhost:5001` باز شده و سامانه آماده استفاده است!

---

## ۴. راهنمای استقرار و نصب روی سرور محلی (Local Server)

### روش اول: اجرای سریع و مستقل با Kestrel (ساده‌ترین روش)
1. فایل `run-local.bat` موجود در پوشه اصلی را با دسترسی ادمین اجرا کنید.
2. سامانه روی پورت `5000` شروع به کار کرده و تمامی کلاینت‌های موجود در شبکه محلی (LAN) می‌توانند با وارد کردن آی‌پی سرور به صورت زیر وارد سامانه شوند:
   ```
   http://192.168.1.X:5000
   ```
3. در فایروال ویندوز سرور (Windows Defender Firewall)، پورت 5000 را در بخش Inbound Rules باز (Allow) کنید.

---

### روش دوم: میزبانی حرفه‌ای سازمانی روی IIS (Internet Information Services)
1. ابتدا مطمئن شوید بسته **.NET Hosting Bundle** روی ویندوز سرور نصب شده باشد.
2. فایل `publish-local-server.bat` را اجرا کنید تا خروجی نهایی پروژه در پوشه `publish` تولید شود.
3. کنسول **IIS Manager** را باز کنید:
   - در بخش **Application Pools**، یک Pool جدید بسازید:
     - نام: `EducationCertPool`
     - .NET CLR Version: روی حالت **No Managed Code** تنظیم شود.
   - در بخش **Sites**، روی `Add Website` کلیک کنید:
     - Site name: `EducationCertPortal`
     - Physical path: آدرس پوشه `publish` را انتخاب نمایید (مثلاً `C:\inetpub\wwwroot\EducationCertPortal`).
     - Binding: پورت مورد نظر (مثلاً پورت 80 یا 8080) و آی‌پی سرور را تنظیم کنید.
   - به پوشه فایل‌های منتشر شده دسترسی خواندن/نوشتن به کاربر `IIS_IUSRS` بدهید تا دیتابیس محلی بتواند ذخیره شود.
4. روی وب‌سایت در IIS کلیک راست کرده و گزینه **Manage Website -> Browse** را بزنید تا سامانه لود شود.

---

### روش سوم: اتصال به پایگاه‌داده Microsoft SQL Server (اختیاری)
اگر در اداره تمایل دارید به جای دیتابیس محلی از SQL Server استفاده کنید:
1. فایل `appsettings.json` را باز کنید.
2. مقدار `"DatabaseProvider"` را از `"Sqlite"` به `"SqlServer"` تغییر دهید.
3. در بخش `"ConnectionStrings"` رشته اتصال `"SqlServerConnection"` را با مشخصات سرور خود تنظیم نمایید:
   ```json
   "ConnectionStrings": {
     "SqlServerConnection": "Server=YOUR_SERVER_NAME;Database=EducationCertPortalDb;Trusted_Connection=True;TrustServerCertificate=True;"
   }
   ```
4. با اولین اجرای پروژه، کلیه جداول و کلیدهای خارجی روی SQL Server به صورت خودکار ایجاد خواهند شد.

---

## ۵. تنظیمات امنیتی و پشتیبان‌گیری
- فایل دیتابیس SQLite در مسیر اجرایی با نام `EducationCertPortal.db` قرار دارد. جهت پشتیبان‌گیری روزانه کافیست این فایل را در انتهای روز کاری کپی یا بایگانی فرمایید.
- تمامی کدهای رهگیری صادر شده با ساختار غیرقابل حدس ۶۰ بیتی (CSPRNG) ذخیره شده و از الگوریتم Modulo-103 برای بارکدهای میله‌ای و فرمت استاندارد QR کد استفاده می‌کنند.
- پسوند شماره دبیرخانه به صورت پیش‌فرض با مقدار `104` طبق ضوابط مالی اداره ملایر تنظیم شده است.
